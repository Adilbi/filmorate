# 🎬 Filmorate

**Filmorate** (от англ. *film* — «фильм» и *rate* — «оценивать») — бэкенд сервиса для работы с фильмами и пользователями.
Сейчас это каркас REST API на Spring Boot: данные хранятся в памяти, входящие запросы проверяются валидацией, ошибки возвращаются с понятными HTTP-кодами.

В следующих версиях сервис будет расти: лайки, друзья, топ популярных фильмов и хранение в базе данных.

## 🚀 Запуск

```bash

mvnw.cmd spring-boot:run

./mvnw spring-boot:run
```

Приложение стартует на `http://localhost:8080`.

Или из IntelliJ IDEA: запустить класс `FilmorateApplication`.

## 📡 API

### Фильмы — `/films`

| Метод | Путь | Описание | Ответ |
|---|---|---|---|
| `POST` | `/films` | Добавить фильм | созданный фильм с `id` |
| `PUT` | `/films` | Обновить фильм (по `id` в теле) | обновлённый фильм |
| `GET` | `/films` | Получить все фильмы | список фильмов |

<details>
<summary>Пример запроса</summary>

```http
POST /films
Content-Type: application/json

{
  "name": "Бен 10: Секрет Омнитрикса",
  "description": "Полнометражный мультфильм",
  "releaseDate": "2009-08-09",
  "duration": 69
}
```

```json
{
  "id": 1,
  "name": "Бен 10: Секрет Омнитрикса",
  "description": "Полнометражный мультфильм",
  "releaseDate": "2009-08-09",
  "duration": 69
}
```
</details>

### Пользователи — `/users`

| Метод | Путь | Описание | Ответ |
|---|---|---|---|
| `POST` | `/users` | Создать пользователя | созданный пользователь с `id` |
| `PUT` | `/users` | Обновить пользователя (по `id` в теле) | обновлённый пользователь |
| `GET` | `/users` | Получить всех пользователей | список пользователей |

<details>
<summary>Пример запроса</summary>

```http
POST /users
Content-Type: application/json

{
  "email": "user@mail.ru",
  "login": "ben10",
  "birthday": "2000-01-01"
}
```

```json
{
  "id": 1,
  "email": "user@mail.ru",
  "login": "ben10",
  "name": "ben10",
  "birthday": "2000-01-01"
}
```
Имя не передано, поэтому вместо него подставлен логин.
</details>

## ✅ Валидация

### Фильм

| Поле | Правило |
|---|---|
| `name` | не может быть пустым |
| `description` | не длиннее 200 символов |
| `releaseDate` | не раньше 28 декабря 1895 года (первый киносеанс) |
| `duration` | положительное число (минуты) |

### Пользователь

| Поле | Правило |
|---|---|
| `email` | не может быть пустым, должен содержать `@` |
| `login` | не может быть пустым и содержать пробелы |
| `name` | может быть пустым — тогда используется `login` |
| `birthday` | не может быть в будущем |

## ⚠️ Ошибки

Ошибки обрабатываются централизованно (`@RestControllerAdvice`) и возвращаются в едином формате:

```json
{ "message": "Название не может быть пустым." }
```

| Ситуация | HTTP-код |
|---|---|
| Данные не прошли валидацию | `400 Bad Request` |
| Объект с указанным `id` не найден при обновлении | `404 Not Found` |

Создание и обновление сущностей, а также причины ошибок пишутся в лог.

## 🧪 Тесты

```bash
./mvnw test
```

Юнит-тесты проверяют валидацию на граничных значениях, например:

- описание ровно 200 символов — проходит, 201 — ошибка;
- дата релиза 28.12.1895 — проходит, 27.12.1895 — ошибка;
- продолжительность 1 — проходит, 0 — ошибка;
- день рождения сегодня — проходит, завтра — ошибка;
- пустое имя пользователя заменяется логином;
- обновление несуществующего объекта — ошибка «не найдено».

Дополнительно API проверено Postman-коллекцией [`postman.json`](postman.json):
импортируйте её в Postman, запустите приложение и выполните **Run collection**.
